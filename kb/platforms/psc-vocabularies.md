# PSC controlled vocabularies

Canonical platform card: [PSC vocabularies](../../registry/platforms/psc-vocabularies.json).

Use [psc-vocabulary](../../skills/psc-vocabulary/SKILL.md) to read an explicitly
authorized local catalog and immutable release. The catalog and manifest need
separate trusted SHA-256 pins. Released artifacts are verified before definitions,
canonical/reused IRIs, legacy replacements and recorded review state are returned.
The inspected authoring contract is commit `7040f2716dffb47f830895b10b9f3e47e50168b1`;
this is no claim about a current hosted release or reader access to it.

A provisional or domain-review-pending definition remains pending. Informational
candidate/rejected/deferred mappings never canonicalize data. Stock-kind concepts
are not operational stocks or membership records. Source refusal remains
unavailable, without network acquisition or a change to permissions.

For creating a new vocabulary use [controlled-vocabulary](../../skills/controlled-vocabulary/SKILL.md).
For generic smn/gcdfo/external ontology discovery use [salmon-terms](../../skills/salmon-terms/SKILL.md).
