# Private research workbench and framework proposals

Structured routing is in [the skill graph](../../registry/skill-graph.json). Use [workbench inspection](../../skills/salmon-workbench-skill/SKILL.md) for private file exports and selected disclosure previews, and [framework proposals](../../skills/salmon-research-framework-skill/SKILL.md) for explicit hypotheses, outcomes and evidence requirements.

One offline helper implements both contracts. Drafts can remain uncommitted; contribution preflight requires a concrete commitment. Expiry requests review, never publication. Identity proposals stay pending or rejected. First-winter and direct-survival evidence entries are necessary but not sufficient for scientific acceptance. No models have been run by these helpers.

The new path does not expand source APIs or change SDK support. Its limitations and primary LSF/BECI citations are maintained in the framework skill references. No paid model behaviour evaluation is implied by offline structural tests.
